# DataShow - App Móvil

Visualizador de cartera de inversiones optimizado para móvil.

## Cómo instalar en Android

1. Abre esta web en **Chrome** (no Safari ni otros navegadores)
2. Toca el banner "📲 Instalar App" que aparece abajo
3. O bien: Menú → "Añadir a pantalla de inicio"
4. Se instalará como una app native

## Uso

1. Sube tu CSV de Degiro
2. Introduce tu ISIN y ticker Yahoo
3. Toca "Cargar Datos"
4. Verás gráficos y estadísticas de tu cartera

## Funcionalidades offline

La app funciona sin conexión tras la primera carga. Los gráficos se cachean automáticamente.

## Requisitos

- Android 7.0+
- Chrome como navegador
